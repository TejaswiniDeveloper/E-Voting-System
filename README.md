# Online E-Voting System

## 📌 Project Overview

The **Online E-Voting System** is a Java-based web application developed to make the voting process easier to manage through an online platform. It allows users to register, sign in, wait for administrator approval, view available candidates, and cast their votes after approval.

The system includes an administrator module to manage voter approvals and candidate information. It uses MySQL to store and manage application data.

This project was developed individually as a practical application of Java web development, database connectivity, and role-based access.

## 🎯 Objectives

- Simplify the voter registration and voting process.
- Provide administrator-controlled voter approval.
- Manage candidate information efficiently.
- Store voter and voting-related data in a MySQL database.
- Organize application access according to user roles.

## ✨ Key Features

### 1. User Registration and Login
- Users can register and sign in to the application.
- Registered users must wait for administrator approval before accessing voting functionality.

### 2. Administrator Module
- Administrator can review registered users.
- Administrator can approve eligible voters.
- Administrator can manage candidate information.

### 3. Candidate Management
- Maintain candidate details in the system.
- Make available candidate information accessible to users through the application.

### 4. Online Voting
- Approved users can access the voting functionality.
- Users can view candidates and cast their votes through the application.

### 5. Database Integration
- MySQL stores application information.
- JDBC connects the Java application to the database.

## 🔄 Application Workflow

1. A user registers on the platform.
2. The user signs in with their credentials.
3. The administrator reviews the registration.
4. The administrator approves the eligible user.
5. The approved user views the available candidates.
6. The user casts a vote through the application.
7. The application uses the MySQL database to manage and store relevant information.

## 🏗️ Project Architecture

The application follows a Java web application structure:

- **Presentation Layer:** HTML, CSS, and JSP pages for the user interface.
- **Application Layer:** Java Servlets handle application requests and processing.
- **Database Layer:** JDBC connects the application to MySQL for data operations.

## 🗄️ Database

The project uses MySQL to manage the application's data, including user registration details, administrator-managed candidate information, and voting-related records.

The database schema and table names depend on the implementation in the project source code.
